Projects

      

        

          
Mobility Workflow Platform

          
A web platform that runs the academic mobility paperwork at IST, from document filling to coordinator validation and post-mobility document reading. It replaced manual data entry, email coordination and disconnected templates.

          
It generates the PEI, the Learning Agreement, the Changes LA and the PEF with correct values for every evaluated user. It is in active use at DEI, and an extension to DEG is under way. Twenty students rated it 89.88 on an adapted System Usability Scale, and the coordinator highlighted the centralised process history and status tracking.

          
Built with HTML/JS, PHP, MySQL, the Fénix API and institutional SSO.

        


        

          
Locally run LLM agents for document workflows

          
Thesis research comparing agent architectures for filling and reading official documents without sending data to external services. Strategies ranged from zero-shot prompting to multi-agent decomposition, iterative self-correction and retrieval-augmented generation. Filling agents were evaluated on 46 real mobility processes and reading agents on 12 real transcripts of records.

          
    
            
  • Model capability is a hard constraint. The gap between Qwen2.5 and Llama 3.2 held across every architecture, so the minimum model size should be established before choosing an architecture.
    • 
            
  • Normalise inputs before any LLM call. Standardising dates, computing derived fields and filtering irrelevant data stops agents from handling structure inconsistently.
    • 
            
  • Name PDF fields for meaning. Descriptive identifiers improved accuracy by up to 30.6 percentage points across every architecture.
    • 
            
  • Vision only works with a capable model. Vision-based reading matched or beat text-based reading with Qwen2.5-VL, while a weaker multimodal model dropped substantially.
    • 
            
  • Plan for human review. The best filling agent reached 81.3% field accuracy, which is a draft rather than a final document, in line with the transparency requirements of the EU AI Act.
    • 
          

          
Built with Ollama, Qwen2.5, Llama 3.2, RAG and multi-agent patterns.
